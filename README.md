# Tutors ("My Coaches")

The "My Coaches" page: a launcher with a button for each of TJ's small phone-friendly apps. The stretching routine is not linked from the page.

Live at https://tjhowlett.github.io/tutors/

`index.html` at the top is the launcher page. Each folder is one app:

- `drawing/`: Sketchbook, a drawing tutor. Lessons are built around 16 tracked skills. The folder also holds its design, hand-over and change-log notes (`.md` files).
- `blues-piano/`: Blues Piano Tutor, with Today, Full Plan and Resources tabs.
- `drone-tutor/`: Drone Tutor, a set of drone lessons. `sw.js` saves an offline copy so it opens with no signal.
- `morning-exercise-routine/`: Morning Movement, a timed exercise routine (two sets, A and B) with a countdown and rest breaks.
- `stretching-routine/`: Jasmin's stretching routine, a timed warm-up, stretch and cool-down routine with a countdown.

The Daily Quiz and Art of War Daily buttons on the launcher open the apps in the Daily-Activities site (https://tjhowlett.github.io/Daily-Activities/), not folders here.
