# Drawing tutor app — video library & materials reference (addendum to Stage 2 bank)

This content was locked in the original design reference document but was
NOT carried into the Stage 2 exercise bank content handed over earlier —
it needs to be added to each skill's bank entry now.

**Scope note for Claude Code:** this is going into the exercise bank
(Stage 2), which Stage 3 (selection engine) and Stage 4 (session screen)
have already been built against. Please check whether either of those
stages assumed the bank entry only contains task text, criteria, and a
reference-photo flag — if so, those assumptions need updating too, not
just the bank data itself. Flag anything Stage 3/4 needs revisiting for
before proceeding.

Each of the 16 skills gets:
- Up to 3 video links (trusted-channel videos, curated for that skill)
- A materials tip is NOT per-skill — it's a small, separate general
  reference (see bottom of this file) the AI can optionally draw on when
  giving feedback (e.g. suggesting a softer pencil), not tied to any one
  skill or exercise

## Trusted channels

Drawabox, Proko, Draw with Jazza, Ctrl+Paint, Circle Line Art School.
Anything outside these five is labelled a **Secondary Source** in the list
below and should be flagged as such wherever it's shown/used — these were
included only where a trusted channel didn't have a clean match.

Preference was ~10 minutes per video, not a hard cap — a few longer videos
are included where they were the best available option (flagged where
relevant).
